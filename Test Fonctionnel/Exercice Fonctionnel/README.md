# Lancement

Pour lancer l'application, vous pouvez utiliser les commandes suivantes :

```bash
npm install

npm run dev

# Lancer l'application en mode production
npm start
```

Pour lancer les tests en arrière-plan :
npm run test:e2e

Pour ouvrir l'interface interactive de Cypress
npm run cypress:open
